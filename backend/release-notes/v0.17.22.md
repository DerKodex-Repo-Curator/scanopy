This release is built around finding and organizing things. A new global search palette spans every entity type, hosts and subnets now roll up into collapsible trees, and tags gained groups, icons and colours.

## New Features

- Add a global search palette on `/` that searches hosts, subnets, VLANs, sites, tags and more from one box ([#2a2df43](https://github.com/scanopy/scanopy/pull/2))
- Group hosts by their virtualization tree and nest subnets inside their parents, so hypervisors, guests collapse into readable sections ([#16df96](https://github.com/scanopy/scanopy/pull/16))
- Introduce tag groups, letting you define mutually exclusive sets like Status ([#02e089](https://github.com/scanopy/scanopy/pull/5))
- Add asset tags to hosts, discovered automatically from ENTITY-MIB or entered by hand ([#8c5226](https://github.com/scanopy/scanopy/pull/8))
- Make VLANs taggable and give them a full detail modal showing name, site and tags ([#86fb61](https://github.com/scanopy/scanopy/pull/86))

## Improvements

- Switch lists to table views by default and retire the card view, so every entity list looks and behaves the same ([#da7025](https://github.com/scanopy/scanopy/pull/7))
- Rework entity modals with consistent layouts, paired short fields, floating icon and tag pickers, and caret navigation to step between entities without closing the dialog ([#fa57f8](https://github.com/scanopy/scanopy/pull/57))
- Fold bulk actions into the list toolbar and float bulk tagging at the bottom of the list, making multi-select edits easier to reach ([#4e74bf](https://github.com/scanopy/scanopy/pull/4))
- Unify page headers with larger titles, sub-tabs in the title row, and a sticky toolbar that keeps result counts and paging in view while you scroll ([#e39be0](https://github.com/scanopy/scanopy/pull/39))
- Rename Network to Site and if-entries to interfaces throughout the UI for clearer, more familiar terminology ([#f4ef4a](https://github.com/scanopy/scanopy/pull/4))
- Accept additional OIDC audiences and verify the authorized party, so SSO works with more identity provider configurations ([#e19341](https://github.com/scanopy/scanopy/pull/19))

## Bug Fixes

- Fix topology keyboard shortcuts and show the correct key hints for your operating system ([#36b36e](https://github.com/scanopy/scanopy/pull/36))
- Persist Docker daemon configuration on its volume so settings survive container restarts and upgrades ([#0d72c4](https://github.com/scanopy/scanopy/pull/72))
