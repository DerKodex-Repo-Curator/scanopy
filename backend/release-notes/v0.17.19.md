This release brings SSH and Wake-on-LAN into the credential system, plus a reworked credential picker and per-user date formatting.

## New Features

- Add SSH and Wake-on-LAN credential types, including an SSH login probe, per-OS script paths, and descriptions so you can tell similar credentials apart ([#744](https://github.com/scanopy/scanopy/pull/744)).
- Rework the credential picker with integration-first grouping, categories, checkboxes, expandable rows, and a total count, making it far easier to find the right credential on large installs ([#746](https://github.com/scanopy/scanopy/pull/746)).
- Add per-user date and time display settings that now apply consistently to every table and timestamp in the app ([#743](https://github.com/scanopy/scanopy/pull/743)).

## Improvements

- Highlight every matching node when hovering a topology filter, and extend the staleness filter to cover IPs and containers ([#742](https://github.com/scanopy/scanopy/pull/742)).
- Use each daemon's recorded operating system when upgrading or reconfiguring it, so you no longer have to pick it manually ([#749](https://github.com/scanopy/scanopy/pull/749)).
- Truncate long modal titles and move tabs and steppers into the title row, giving dialogs more usable space ([#753](https://github.com/scanopy/scanopy/pull/753)).
- Show host pickers in pages with readable titles for IP-named hosts, so long lists are easier to scan ([#747](https://github.com/scanopy/scanopy/pull/747)).

## Bug Fixes

- Fix missing creation dates on newly created client IDs ([#756](https://github.com/scanopy/scanopy/pull/756)).
