This release is focused on knowing what your devices actually are — Scanopy now detects and displays operating systems across your network — plus a much more flexible entity table.

## New Features

- Detect host operating systems automatically from service banners, HTTP headers, mDNS, LLDP, SMB and container engines, ranking readings by source reliability so you see the most trustworthy answer ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Show OS tags with platform icons throughout the app, including tooltips explaining how an OS was inferred ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Report a daemon's operating system during handshake, so machines running a daemon no longer ask you to pick their OS manually ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Sort, group and filter on every entity field, with filter and grouping controls available directly from table column headers and options drawn from the data in the tab you're viewing ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Reorder entity table columns by dragging, with the full set of fields available to add ([#761](https://github.com/scanopy/scanopy/pull/761)).

## Improvements

- Replace the integration picker with per-type setup hints that link straight to the relevant docs ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Show an install-daemon prompt on the home page after you dismiss the onboarding checklist, so it's still easy to find ([#761](https://github.com/scanopy/scanopy/pull/761)).
- Fill in missing subnets, credentials and descriptions in the demo environment for a more realistic first look ([#761](https://github.com/scanopy/scanopy/pull/761)).
