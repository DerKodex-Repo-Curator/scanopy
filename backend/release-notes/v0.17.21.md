This release brings virtualization into the picture: Scanopy now talks to Proxmox VE, links guests to the hosts they run on, and surfaces virtualization details throughout the UI. Alongside that, tables, tags and the inspector all got more informative.

## New Features

- Add a Proxmox VE integration that discovers your nodes and guests, links each VM or container to the host it runs on, and shows guest type, OS, hostname and virtualization details in device details ([#763](https://github.com/scanopy/scanopy/pull/763)).
- Add table density and column resizing so you can fit more rows on screen or widen the columns you actually care about ([#764](https://github.com/scanopy/scanopy/pull/764)).
- Introduce collapsible inspector sections with metadata, making long entity panels easier to scan ([#764](https://github.com/scanopy/scanopy/pull/764)).

## Improvements

- Give every tag a name and a tooltip, and collect hidden tags behind an (i) icon instead of dropping them, so you can see the full picture without crowding the row ([#764](https://github.com/scanopy/scanopy/pull/764)).
- Show port details in a hover popover on port chips, saving a trip into the host inspector ([#764](https://github.com/scanopy/scanopy/pull/764)).

## Bug Fixes

- Fix host matching so devices proven to be the same hardware are merged, a second address behind one MAC is kept, and ipvlan guests are no longer confused with their host ([#763](https://github.com/scanopy/scanopy/pull/763)).
- Fix dependency editing so members added while editing are saved and the panel stays in edit mode as you change them ([#763](https://github.com/scanopy/scanopy/pull/763)).
- Keep long labels from pushing the "+N more" chip out of view and wrap labels that overflow their row ([#764](https://github.com/scanopy/scanopy/pull/764)).
