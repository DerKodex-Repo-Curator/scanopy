This release focuses on a major improvement to Scanopy's tagging system, plus new ways to export your topology diagram.

## New Features

- Introduce tag groups as a first-class entity, letting you create, order and scope your own groups, filter by tag per view, and pick tags from chips in table column filters.
- Export any topology view to draw.io or Visio, with host and device details carried along as shape data so your diagrams stay useful outside Scanopy (Business plan).
- Add an in-app release notes modal and upgrade email, so you can see what changed and get the exact upgrade command for your deployment.
- Detect Calibre, Calibre-Web and Dawarich during service discovery.

## Improvements

- Keep topology display and layout choices with each view, so switching views no longer resets how you had things arranged.
- Speed up topology loading on large networks by building only the view you asked for and holding the existing layout steady while a scan runs.

## Bug Fixes

- Fix installs on machines where the architecture reports as `amd64`, which previously caused `install.sh` to bail out.
- Fix older `config.json` files not being migrated in all cases when upgrading from earlier versions.
- Stop profile updates from overwriting server-managed fields on your user account.
- Fix retired Windows binaries sharing a single name, making them impossible to tell apart.
- Fix quoted `op://` secret references in `.env` files not being recognized.
