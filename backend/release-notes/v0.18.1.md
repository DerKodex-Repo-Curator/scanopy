This release focuses on getting discovery results actionable faster: scans now tell you when they've found something that needs credentials, and the entity tables got a productivity overhaul.

## New Features

- Prompt for credentials when a scan finds SNMP, Docker, or Podman integrations, so you can turn a bare port into full device or container detail in a couple of clicks.
- Add SNMPv3 security levels and MD5 authentication, widening the range of devices Scanopy can poll.
- Show recent scan outcomes on the home page, including how many warnings each run produced and which ones you can resolve.
- Notify admins with an in-app banner when a new Scanopy release is available.
- Email cloud users ahead of any terms of service update, with a link to the exact dated version of the terms.

## Improvements

- Make entity tables faster to work with: keyboard shortcuts for create, delete and select-all, actions for the selected row right in the toolbar, resizable columns and a clearer summary row.
- Store list filters and search in the URL so you can bookmark or share a filtered view.
- Apply your active filters to host and service exports, so what you download matches what you see.
- Group credentials by integration by default and tidy the tag picker, making both easier to scan at a glance.
- Clarify in-app guidance around light vs. full port scans, the Docker socket mount and server deletion.
- Keep Settings reachable when a license is locked, so you can fix licensing without being shut out.
- Include resolvable warnings and credential prompts in the digest email, with consistent host names throughout.

## Bug Fixes

- Fix containers and services losing their open ports after re-discovery, which could make hosts disappear from topology views ([#784](https://github.com/scanopy/scanopy/issues/784)).
- Fix daemons failing to reconnect when their saved identity went stale.
- Fix daemon logging silently stopping when the log file could not be written, now falling back to standard output.
- Fix in-flight requests and live event streams being cut off abruptly during restarts and upgrades.
